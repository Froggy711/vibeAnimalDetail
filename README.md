Animex | World of Animals 🦁

Animex เป็นเว็บไซต์เพื่อมาให้ข้อมูลสัตว์ต่างๆแก่ผู้ใช้ ตามประเภทต่างๆ เช่น สัตว์บก สัตว์น้ำ สัตว์ปีก

 คุณสมบัติเด่น (Features)
 **การจำแนกประเภท**: แยกหมวดหมู่สัตว์ออกเป็น สัตว์บก, สัตว์น้ำ และสัตว์ปีก
 **แนะนำสัตว์ (Recommended)**: ระบบสุ่มแนะนำสัตว์ที่น่าสนใจ 6 ตัว ในหน้าหลัก
 **ข้อมูลรายละเอียด**: มีระบบ Modal แสดงข้อมูลถิ่นที่อยู่ อาหาร และรายละเอียดทั่วไปของสัตว์แต่ละชนิด
 **Responsive Design**: รองรับการใช้งานบนทุกอุปกรณ์ ทั้งคอมพิวเตอร์และมือถือ
