# Animex | World of Animals 🌍🦁

**Animex** เป็นเว็บไซต์สารานุกรมสัตว์โลกที่รวบรวมข้อมูลที่น่าสนใจเกี่ยวกับสัตว์นานาชนิดจากทั่วทุกมุมโลก ออกแบบมาเพื่อการเรียนรู้ด้วยดีไซน์ที่ทันสมัยและใช้งานง่าย

## ✨ คุณสมบัติเด่น (Features)
- 🧪 **การจำแนกประเภท**: แยกหมวดหมู่สัตว์ออกเป็น สัตว์บก, สัตว์น้ำ และสัตว์ปีก
- ⭐ **แนะนำสัตว์ (Recommended)**: ระบบสุ่มแนะนำสัตว์ที่น่าสนใจ 4 ชนิดในหน้าหลัก
- 🔍 **ข้อมูลรายละเอียด**: มีระบบ Modal แสดงข้อมูลถิ่นที่อยู่ อาหาร และรายละเอียดทั่วไปของสัตว์แต่ละชนิด
- 🎨 **ดีไซน์ทันสมัย**: ใช้ Glassmorphism และ Micro-animations เพื่อประสบการณ์การใช้งานที่ยอดเยี่ยม
- 📱 **Responsive Design**: รองรับการใช้งานบนทุกอุปกรณ์ ทั้งคอมพิวเตอร์และมือถือ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5**: สำหรับโครงสร้างของหน้าเว็บ
- **Vanilla CSS**: สำหรับการตกแต่งและแอนิเมชัน (Glassmorphism design)
- **JavaScript (Vanilla)**: สำหรับการจัดการข้อมูลสัตว์ การกรองข้อมูล และระบบ Modal
- **Google Fonts**: ใช้ฟอนต์ 'Kanit' และ 'Outfit'
- **Font Awesome**: สำหรับไอคอนที่สวยงาม

## 📁 โครงสร้างโปรเจกต์
- `index.html`: หน้าหลักของเว็บไซต์
- `about.html`: หน้าข้อมูลเกี่ยวกับเรา
- `styles.css`: ไฟล์สไตล์หลักและการออกแบบแอนิเมชัน
- `script.js`: ไฟล์ตรรกะและการจัดการข้อมูลสัตว์

## 🚀 การใช้งานเบื้องต้น
1. Clone repository นี้ไปยังเครื่องของคุณ
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์
3. สนุกกับการสำรวจโลกแห่งสัตว์มหัศจรรย์!
